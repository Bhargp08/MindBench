# MindBench

A preregistered online experiment battery for attention, perception and memory, analyzed with Bayesian hierarchical and drift-diffusion models.

This is a personal, preregistered self-experiment (N = 1 main participant). No institutional review board review has been obtained.

Status: MB-01 (ethics docs). See `docs/status/STATUS.md`.

Licenses: code MIT (`LICENSE`); released data CC-BY-4.0 (at release time).

## Data sources

Free-recall words are selected from the EFF Large Wordlist by Joseph Bonneau / Electronic Frontier Foundation (https://www.eff.org/deeplinks/2016/07/new-wordlists-random-passphrases), used under EFF's CC BY policy. See `docs/design/wordpool.md`.
