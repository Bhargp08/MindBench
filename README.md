# MindBench

A preregistered online experiment battery for attention, perception and memory, analyzed with Bayesian hierarchical and drift-diffusion models.

This is a personal, preregistered self-experiment (N = 1 main participant). No institutional review board review has been obtained.

Status: MB-00 (repo skeleton). See `docs/status/STATUS.md`.
